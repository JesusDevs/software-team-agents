# Linear & Jira Ticket Templates

## Linear Issue Template
```
**Title:** [Action] [Object] — e.g., "Add OAuth login with Google"

**Type:** Feature / Bug / Improvement / Task

**Priority:** Urgent / High / Medium / Low

**Description:**
[Context: Why is this needed?]

**Acceptance Criteria:**
- [ ] Criterion 1
- [ ] Criterion 2

**Technical Notes:**
[Any technical constraints or hints for the dev]

**Labels:** frontend, backend, auth, payments...
**Estimate:** [story points]
**Cycle:** Sprint X
```

## Jira Story Template
```
Summary: [US-XXX] As a [user] I want to [action]

Description:
**User Story:**
As a [user type]
I want [feature]
So that [benefit]

**Acceptance Criteria:**
1. Given [context] When [action] Then [result]
2. ...

**Definition of Done:**
- [ ] Code merged to main
- [ ] Tests written and passing
- [ ] Reviewed by 2 team members
- [ ] PO accepted in staging

**Story Points:** [1/2/3/5/8]
**Sprint:** Sprint [N]
**Epic Link:** [Epic name]
```

## Epic Template
```
Epic Name: [Descriptive name]
Goal: [What business value does this deliver?]
Timeline: Sprint [X] to Sprint [Y]

Stories in this Epic:
- US-001: ...
- US-002: ...

Success Metric: [How do we know this epic is done?]
```
